# 📄 Penerapan Metode Latent Semantic Analysis (LSA) untuk Text Summarization pada Dokumen Undang-Undang Pelindungan Data Pribadi

> 📚 Proyek Text Mining yang menerapkan metode **Text Summarization** pada dokumen **Undang-Undang Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi (UU PDP)** menggunakan algoritma **Latent Semantic Analysis (LSA)** dengan pendekatan **Extractive Summarization**. Hasil ringkasan dievaluasi menggunakan metrik **ROUGE** dan **Compression Rate**.

---

## 🎯 Tujuan Proyek

* 📝 Menerapkan teknik Text Summarization pada dokumen hukum.
* 🤖 Menghasilkan ringkasan otomatis dari dokumen UU PDP.
* 📉 Mengurangi panjang dokumen tanpa menghilangkan informasi penting.
* 📊 Mengevaluasi kualitas ringkasan menggunakan ROUGE dan Compression Rate.

---

## 🧠 Metode yang Digunakan

### 📌 Metode

* Text Summarization

### 🔍 Pendekatan

* Extractive Summarization

### ⚙️ Algoritma

* Latent Semantic Analysis (LSA)

### 📈 Evaluasi

* ROUGE-1
* ROUGE-2
* ROUGE-L
* Compression Rate

---

## 📂 Dataset

Dataset yang digunakan berupa dokumen:

📜 **Undang-Undang Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi (UU PDP)**

### 📋 Format Data

* 📄 PDF Document
* 🇮🇩 Bahasa Indonesia
* ⚖️ Kategori: Dokumen Hukum

## 🔄 Alur Penelitian

1. 📥 Ekstraksi teks dari dokumen PDF menggunakan PyMuPDF.

6. 📉 Visualisasi hasil summarization.

## 📊 Hasil Evaluasi

✅ Metode **Latent Semantic Analysis (LSA)** berhasil menghasilkan ringkasan otomatis dari dokumen **UU Pelindungan Data Pribadi** dengan tingkat kompresi yang tinggi.

Evaluasi dilakukan menggunakan:

* 📌 **ROUGE Score** untuk mengukur kemiripan antara ringkasan sistem dan ringkasan referensi.
* 📌 **Compression Rate** untuk mengukur tingkat pengurangan jumlah kata dari dokumen asli.
